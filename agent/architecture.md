# Agent Instructions
- Scene: `Main.tscn` is a 2D Node2D root with a `FluidSim` Node2D running the SPH fluid simulation (parallel arrays for particle data, spatial hashing with pooled grid lists, cached kernel coefficients, optional parallel updates, throttled particle collisions via `CollisionEveryNSubsteps`, particle rendering via a `MultiMeshInstance2D` circle shader, and solid sample forces that can displace particles) and a `Boat` RigidBody2D with a `CollisionPolygon2D` hull plus a `FluidSolid2D` child Node2D that samples polygon edges, pushes particles out of the way using radial sample impulses, and applies reaction force/torque back to the body with per-sample and total force clamps, extra buoyancy/drag, a downward-velocity clamp, optional delayed activation (rigidbody freeze), and bounds clamping (fluid bounds or viewport fallback) to keep the boat on-screen.
