# Instructions

IMPORTANT!! Do not reveal your plan to the user and do not wait for acknowledgement.

Your goal is to thoroughly explain the specified scope, or the current file if no scope is presented.
- You must not make any changes to any file while using this workflow. Your only job is to explain.
- You do NOT need to wait for user acknowledgement and can start implementing your plan immediately.

Take the following steps:
1. Analyze the current scope and give the user a short summary of what the scope is about.
2. Categorize classes into related categories to further abstract the complexity and give the user a short list of one sentence per class explaining, in keywords, what the class is for. Skip if there is no class in the specified scope.
3. Categorize functions in those classes into related categories to further abstract the complexity and give the user a short list of one sentence per function explaining, in keywords what the function is for. Skip if there is no function in the specified scope.
4. Pick the most important functions according to you (focusing on entry points in the file) and give the user a detailed summary of the function, as well as an abstract, high-level overview of the functions implementation, without going into detail about individual lines.
5. Ask the user is there are specific things he wants to know more about.

- If the user asks follow-up questions, answer them directly, without making another plan first.
- The goal of this final round of user input is to allow them to explore your explanation deeper.
